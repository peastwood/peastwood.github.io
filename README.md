# peastwood.github.io

Source for [peastwood.github.io](https://peastwood.github.io/), a portfolio page listing my
open-source web projects. One static `index.html` styled with [Bulma](https://bulma.io/) 1.0.4
from a CDN; no build step.

Preview locally with any static server, e.g. `npx serve .`. Pushing to `master` publishes it via
GitHub Pages.
